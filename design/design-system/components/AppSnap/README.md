# AppSnap

Snap the list. The camera with a sideways mode strip (Cocktails, Wine list, Menu) and a sheet underneath where wines stream in as they are extracted. A wine already on their to-try list is badged; a line it couldn't read is tinted vv-warning with "Reshoot closer". There is no Done button: swipe the sheet up for the analysis.

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame. Design: `design/canvas/Vino Vibes App v2.dc.html`, option 2l.

Code: `src/components/landing/screens/AppSnap.tsx`, built from the parts in `parts.tsx`.
