# AppSnap

The camera, opened on the wine list. Capture modes swipe like the iOS camera (Spirits, Cocktails, Wine list, Menu, Dessert); brackets in vv-stroke frame the page; a chip counts wines as they're read; "Type it instead" is the fallback.

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame.

Code: `src/components/landing/screens/AppSnap.tsx`, built from `Screen`, `TopBar`, `SectionLabel` and `Row` in `parts.tsx`.
