# AppCheckIn

Next-day check-in, in the same thread the next morning. One card collects the verdict on the wine, the pairing score and "wish you'd tried", which feed the library and the palate. One gradient button: "Save to library".

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame. Design: `design/canvas/Vino Vibes App v2.dc.html`, option 2j.

Code: `src/components/landing/screens/AppCheckIn.tsx`, built from the parts in `parts.tsx`.
