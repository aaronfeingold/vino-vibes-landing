# AppWine

One wine, over time. Opened from any library row: how many times they've had it, where and with what, how locals in the neighbourhood drink it, and where to get it nearby.

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame. Design: `design/canvas/Vino Vibes App v2.dc.html`, option 2e.

Code: `src/components/landing/screens/AppWine.tsx`, built from the parts in `parts.tsx`.
