# AppMemory

What I know about you: traits with where they came from and what they change, taste chips (liked in vv-glow 16%, avoided struck through), and recent bottles. Every item can be forgotten. Only the person can see it.

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame.

Code: `src/components/landing/screens/AppMemory.tsx`, built from `Screen`, `TopBar`, `SectionLabel` and `Row` in `parts.tsx`.
