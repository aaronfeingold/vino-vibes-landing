# AppNearby

Tonight, nearby: the street-corner case ("fish and a Chardonnay, close by"). Filters, a map, and ranked places that have both, combining scanned menus, their own history and what locals order.

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame. Design: `design/canvas/Vino Vibes App v2.dc.html`, option 2f.

Code: `src/components/landing/screens/AppNearby.tsx`, built from the parts in `parts.tsx`.
