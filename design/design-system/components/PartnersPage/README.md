# PartnersPage

Partner with us, at `/partners`: the page for restaurants, bars and wine shops, asking them to try Vino Vibes in service for free in return for honest feedback.

Built from: Navbar, a page hero (eyebrow "FOR RESTAURANTS, BARS AND WINE SHOPS", `page-title` "Try Vino Vibes at your tables, free.", a lead, a primary "I'm interested" button that jumps to the form, the hero glow at 20%), a `vv-band` section "What you get" with three offer Cards, "How it works" as four Steps, "Let's talk" with the PartnerForm, and the Footer.

- One gradient button above the fold ("I'm interested") and the same label on the form's button, so the ask never changes.
- The offer is in plain terms: free seats for staff, a table card with a code for guests, their own list loaded so picks are things they pour at their prices.
- Reached from the nav ("For restaurants") and the strip at the end of Home ("Partner with us").
- Metadata: title "Partner with Vino Vibes", canonical `/partners`.
