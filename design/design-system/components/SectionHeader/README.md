# SectionHeader

How every section opens: an eyebrow, a headline, and sometimes a lead.

- Eyebrow: 14 px 600, uppercase, 0.12em tracking, `vv-accent`. Short: "HOW IT WORKS", "MADE FOR THE CONNOISSEUR", "FOR RESTAURANTS, BARS AND WINE SHOPS".
- Headline: `section` (44 px 800, -0.02em) on Home, `section-sm` (40 px) on Partner with us, both 32 px under 900 px. Plain and confident: "Ninety seconds, start to pour."
- Lead: `body-lg` or `lead` in `vv-text2`.
- Centred above a grid of phones; left-aligned beside a phone or a form. Some sections go without an eyebrow ("What you get", "Let's talk").
