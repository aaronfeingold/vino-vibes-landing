# AppLibrary

Wine library by place. Each restaurant or trip is a card listing what they drank there, repeat counts, verdicts and what they missed (tinted vv-warning, "To try"). Places, Wines and Nearby are tabs.

Sample restaurant: Maison Lune (invented). Wines are real producers with representative prices. The screen is 390 × 844 and appears on the site inside a PhoneFrame. Design: `design/canvas/Vino Vibes App v2.dc.html`, option 2d.

Code: `src/components/landing/screens/AppLibrary.tsx`, built from the parts in `parts.tsx`.
